## Overview

**호텔 예약 취소에 대한 데이터 기반 분석 및 보고.**
모델 학습 없이 **EDA와 통계 해석만으로 비즈니스 인사이트를 도출**하는 것이 목적인 미션.
결과물은 예측 모델이 아니라 **의사결정용 리포트**다.

## Key Files

- `미션2_6팀_신호정.ipynb` — 제출본 (분석 + 보고)
- `호텔 예약 취소 분석.ipynb` — 작업용 사전 분석 노트북
- `hotel_data_modified.csv` (13MB) — 원본 데이터 (동봉)
- `NanumGothic.ttf` — matplotlib 한글 폰트

## 핵심 분석 결과

- **예약 취소율 37%** — 예약 10건 중 실제 체크인은 6건 남짓
- No-Show는 전체의 약 1%로, 취소 대비 미미한 비중
- **2인 예약**이 최다 비중이면서 전체 평균보다 취소율이 높음 → 사후 관리 대상
- 특별 요청 · 주차장 요청이 취소율에 극적인 영향

## Dependencies

`pandas` / `matplotlib` / `seaborn` 만 사용. 딥러닝 프레임워크 · GPU 불필요.

## 작업 시 유의점

- 데이터가 폴더에 동봉되어 있어 **노트북을 그대로 실행할 수 있다** (경로 수정 불필요).
- 이 미션은 `A. / A-a.` 계층 표기를 쓰지 않는다 (미션 05부터 도입된 규약).
- 결론 섹션의 주장은 모두 앞선 그래프에 근거한다. 수치를 바꿀 경우 결론도 함께 갱신할 것.
