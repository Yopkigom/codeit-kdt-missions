K-DT 과정의 첫 미션으로, 모델링 요소는 없고 순수 Python 구현 문제 풀이로 구성된다.

## Dependencies

표준 라이브러리만 사용 (`csv`, `uuid`, `asyncio`). 외부 패키지 · GPU 불필요.

## 작업 시 유의점

- 각 문제는 **함수 시그니처가 문제에 명시**되어 있다. 시그니처를 바꾸지 말 것.
- 카운트다운 타이머 문항은 `asyncio` 기반이라 노트북에서 실행 시 이벤트 루프 충돌에 주의.
- 이 미션은 다른 미션과 달리 `A. / A-a.` 계층 표기를 쓰지 않는다 (미션 05부터 도입된 규약).
