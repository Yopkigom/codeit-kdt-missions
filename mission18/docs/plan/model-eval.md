# 미션 18 모델 실측 기록 (B 섹션)

미션 13 ONNX 자산을 미션 18에 그대로 재사용하기 전에 수행한 실측이다.
보고서의 "도메인 이동에 따른 모델 성능 변화" 항목의 근거 자료다.

## A. 모델 사양 (실측)

| 항목 | 값 |
|---|---|
| 파일 | `modelA_full_ft.onnx` + `.onnx.data` (합계 약 127MB) |
| 입력 | `input_ids` · `attention_mask` · `token_type_ids`, 각 `[1, 256]` **int32** |
| 출력 | `logits` `[1, 3]` — **raw logit**, softmax 미적용 |
| `max_length` | **256** (Fixed Shape, 세션 입력 shape에서 읽는다) |
| 토크나이저 | WordPiece(`tokenizer.json`), `[PAD]` id = 0 |

출력 합이 1이 아니고 음수를 포함하므로 후처리에서 softmax를 직접 적용한다(B-b-3).

## B. 라벨 매핑 (B-c-1)

`config.json`의 `id2label`은 `LABEL_0~2`뿐이라 의미를 담고 있지 않다.
아래 두 근거가 일치하므로 확정한다. **추정이 아니다.**

1. 미션 13 노트북 학습 코드 — `LABEL_MAP = {'-1': 0, '0': 1, '1': 2}`,
   `label_names = {0: '부정', 1: '중립', 2: '긍정'}`
2. 골든 케이스 추론 실측 (아래)

| 인덱스 | 감성 | 스칼라 | 화면 표기 |
|---|---|---|---|
| 0 | 부정 | -1 | `별로에요` |
| 1 | 중립 | 0 | `보통` |
| 2 | 긍정 | +1 | `좋아요` |

### B-a. 골든 케이스 (B-c-2)

긍정 3 · 중립 3 · 부정 3건. **9건 중 8건 일치.**

| 기대 | 입력 | 예측 | 확신도 |
|---|---|---|---|
| 긍정 | 정말 재미있게 봤어요… | 긍정 | 0.998 |
| 긍정 | 인생 영화입니다… | 긍정 | 0.998 |
| 긍정 | 완벽한 연출과 각본… | 긍정 | 0.998 |
| 중립 | 그냥 무난했어요. 나쁘지도 좋지도 않네요. | **부정** | 0.784 |
| 중립 | 볼만은 한데 특별히 인상적이지는… | 중립 | 0.690 |
| 중립 | 평범한 영화. 시간 때우기용… | 중립 | 0.896 |
| 부정 | 최악이었어요… | 부정 | 0.998 |
| 부정 | 지루하고 재미없다… | 부정 | 0.997 |
| 부정 | 연기도 각본도 형편없었다… | 부정 | 0.998 |

긍·부정은 확신도 0.99대로 일관되고, **중립만 0.69~0.90으로 낮고 1건은 오분류**된다.
중립이 세 클래스 중 가장 불안정하다는 점이 이후 임계값 설정의 근거가 된다.

## C. 도메인 이동 성능 (B-c-5)

미션 13 학습 도메인은 쇼핑몰·SNS 리뷰, 본 미션 추론 대상은 영화 리뷰(NSMC)다.
NSMC test 3,000건 무작위 표본(`SEED=42`)으로 측정했다.

**NSMC는 이진 라벨(0=부정 / 1=긍정)이고 중립 정답이 없다.** 따라서 지표를 둘로 나눈다.

| 지표 | 값 |
|---|---|
| 미션 13 자체 도메인 test accuracy (참고) | 0.8847 |
| **엄격 정확도** (중립 예측을 오답 처리) | **0.6543** |
| **중립 제외 이진 정확도** (2,400건 대상) | **0.8179** |
| 중립 예측 비율 | 0.2000 |

### C-a. 혼동 행렬

| 정답 \ 예측 | 긍정 | 부정 | 중립 |
|---|---|---|---|
| 부정(0) | 134 | 1,123 | 257 |
| 긍정(1) | 840 | 303 | 343 |

부정 정답의 긍정 오분류는 134건인 반면, 긍정 정답의 부정 오분류는 303건이다.
**부정 쪽으로 치우친 예측 경향**이 있다.

### C-b. confidence 구간별 정확도

| confidence | 건수 | 엄격 정확도 | 중립 예측 비율 | 이진 정확도 |
|---|---|---|---|---|
| ~0.50 | 58 | 0.293 | 0.483 | 0.567 |
| 0.50~0.60 | 233 | 0.270 | 0.545 | 0.594 |
| 0.60~0.70 | 231 | 0.377 | 0.476 | 0.719 |
| 0.70~0.80 | 281 | 0.381 | 0.420 | 0.656 |
| 0.80~0.90 | 351 | 0.479 | 0.402 | 0.800 |
| 0.90~0.95 | 314 | 0.669 | 0.169 | 0.805 |
| **0.95~1.00** | **1,532** | **0.856** | 0.015 | **0.869** |

**confidence는 정확도와 단조에 가깝게 증가한다.** 즉 `max(softmax)`를 저확신 표기의
기준으로 쓰는 것이 실측으로 정당화된다. 0.90 미만 구간은 엄격 정확도가 0.5를 밑돈다.

## D. Truncation 영향 (B-c-3)

NSMC 표본 3,000건에서는 **truncation이 한 건도 발생하지 않았다**(NSMC 리뷰는 최대 140자).
따라서 긴 입력을 인위적으로 만들어 별도 점검했다.

| 사례 | 앞 200자만 | 전체(700자+, 잘림) |
|---|---|---|
| 앞=긍정 / 뒤=부정 | 긍정 0.988 | 긍정 0.578 |
| 앞=부정 / 뒤=긍정 | 부정 0.987 | **긍정 0.500** |

- 모델은 앞 256토큰만 본다. **뒤쪽 반전 문장은 판단에 반영되지 않는다.**
- 다만 잘린 입력은 **확신도가 0.50~0.58로 급락**했다. 저확신 표기가
  truncation 사례도 함께 걸러내는 부수 효과가 있다.
- 리뷰 본문 상한 2,000자는 저장 방어선일 뿐이므로, **잘림 여부(`truncated`)를 추론 결과에
  포함**해 필요 시 화면이 안내할 수 있게 했다.

## E. 지연 (참고)

| 조건 | 값 |
|---|---|
| 본 측정 (WSL2, `intra_op_num_threads=1`) | 약 66ms/건 |
| 미션 13 측정 (PyTorch CPU, 스레드 제한 없음) | p50 29ms |

스레드를 1로 고정한 것은 Cloud Run 1 vCPU 환경을 가정했기 때문이다.
정식 지연 측정은 I-b-3에서 컨테이너 기준으로 다시 수행한다.

## F. 해석 및 대응 (B-d-1)

1. **도메인 이동으로 성능이 실제로 떨어진다.** 이진 정확도 0.818은 미션 13 자체
   도메인 0.885 대비 약 7%p 낮다. 재학습 없이 자산을 재사용한 결과이며,
   이를 감추지 않고 보고서에 그대로 싣는다.
2. **엄격 정확도 0.654는 과소평가된 수치다.** NSMC에 중립 정답이 없어 중립 예측
   600건이 전부 오답으로 계산되기 때문이다. 실제로 중립 예측은 확신도가 낮은
   구간에 몰려 있어(0.9 미만에서 40~55%) 모델의 **판단 유보**로 보는 편이 타당하다.
3. **보정 로직은 넣지 않는다.** confidence는 저장·표기용으로만 쓴다.
   CLAUDE.md의 방침대로 관측치 없이 보정 장치를 먼저 설계하지 않으며,
   1차 대응은 화면의 `판정 애매` 표기다.
4. `판정 애매` 임계값은 위 C-b 표를 근거로 정한다(D 섹션에서 확정).
