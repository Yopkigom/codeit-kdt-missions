# CLAUDE.md — 미션 05

상위 규약은 [`../../CLAUDE.md`](../../CLAUDE.md)를 따른다.

## Overview

**오토인코더 기반의 문서 복원 기능 구현.**
훼손되어 가독성이 저하된 문서 이미지를 오토인코더로 복원하고,
복원 품질을 **객관적 수치로 측정**해 최적 기법을 선발하는 미션.

**딥러닝(PyTorch)이 본격 도입되는 첫 미션**이며,
이후 미션 06~14가 공유하는 **환경 설정 골격(섹션 E)이 여기서 확립**된다.

## 핵심 설계 포인트

- **기법 선별(섹션 D)이 연산 장치 여건에서 출발한다.**
  "좋은 기법"이 아니라 "주어진 VRAM·연산 예산에서 실현 가능한 기법"을 고르는 논리 구조.
  On-Device 관점의 사고가 처음 드러나는 지점이며, 미션 13·14로 이어진다.
- **손실 함수도 기법의 일환**으로 취급해 비교 대상에 포함한다 (단순 MSE에 한정하지 않음).
- 사전 학습 모델 활용 가능성도 탐색 범위에 포함.

## Dependencies

`torch`, `torchvision`, `torchmetrics`, `transformers`, `optuna`, `PIL`. **GPU 필요.**

## 작업 시 유의점

- 이 미션부터 `A. / A-a. / A-a-1.` **계층 표기 규약이 적용**된다.
  셀을 지칭할 때는 `D-c의 2번째 셀`처럼 섹션 계층 내 순서로 표기할 것.
- 복원 품질 지표는 `torchmetrics` 기반이다. 시각적 개선과 수치가 어긋날 수 있으므로
  **정성 평가(이미지)와 정량 평가(지표)를 반드시 함께** 볼 것.
